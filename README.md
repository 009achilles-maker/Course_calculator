# حاسبة دورات الإمداد 📅

موقع ويب يساعد في حساب مواعيد دورات مدرسة الإمداد مع تتبع العطلات الرسمية والدينية.

## المميزات ✨

- 📍 حساب تاريخ بداية الدورة (تعديل تلقائي ليكون يوم أحد)
- 📍 حساب تاريخ نهاية الدورة (يوم خميس)
- 📍 تحديد مدة الدورة بالأسابيع
- 📍 رصد العطلات الرسمية والدينية تلقائياً
- 📍 واجهة عربية سهلة الاستخدام

## العطلات المتضمنة 🎉

### العطلات الثابتة
- رأس السنة الميلادية (1 يناير)
- العيد الوطني الكويتي (25 فبراير)
- عيد التحرير (26 فبراير)

### العطلات المتغيرة
- العطلات الدينية (عيد الفطر، عيد الأضحى، إلخ)
- يتم تحديثها تلقائياً لكل سنة

## كيفية الاستخدام 🚀

1. أدخل تاريخ بداية الدورة المطلوبة
2. حدد مدة الدورة بالأسابيع
3. اضغط على "احسب المواعيد"
4. ستظهر تاريخ البداية والنهاية مع أي عطلات متقاطعة
